# 原始运行输出（一次真实运行，逐字粘贴）

这个文件是 README 里所有数字的**唯一出处**。README 只引用这里的数字；
这里没有的数字，README 里也不该出现毫秒值。

## 怎么采的

在作者的一台手机上（Android + proot 的 Linux 容器）依次执行下面三条命令，
`date -u` 的时间戳与命令输出原样重定向到本文件，没有人工编辑中间结果：

```bash
for spec in "--help" "dnsfind" "diagnose --skip-scan"; do
  date -u +"$ python3 -m campusnet $spec   # 开始 %Y-%m-%dT%H:%M:%SZ"
  python3 -m campusnet $spec 2>&1
  date -u +"# 结束 %Y-%m-%dT%H:%M:%SZ"
done
```

只读子命令，没有 `--apply`，没有写任何系统文件。

5. 大包 / MTU
================================================================
         原理：链路 MTU 太小时，带 DF（不分片）的大包会被静默丢弃。

         旧版本用 HTTP POST 四个尺寸来测，TCP 会按 MSS 分段，四个尺寸必然全 OK ——
         那种做法测不出 MTU 问题，本工具已不再据此建议改 MTU。
